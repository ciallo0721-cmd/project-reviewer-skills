# 多维度项目审查检查清单

## 角色 1：创意审查官 — 详细检查项

### 视觉层级
- [ ] H1/H2/H3 标题体系是否明确，字号差异≥2pt
- [ ] 正文与标注/说明文字是否有明显区分
- [ ] CTA（行动按钮）是否足够突出，对比度≥4.5:1（WCAG AA标准）
- [ ] 关键信息（价格、错误提示、必填项）是否有视觉强调

### 间距与对齐
- [ ] 相关元素之间的间距是否小于不相关元素之间的间距（格式塔邻近原则）
- [ ] 所有元素是否对齐到统一的基准线或网格
- [ ] 内边距（padding）是否一致（建议统一为4的倍数：8/12/16/24/32px）
- [ ] 移动端是否保留足够触控区域（最小44×44px）

### 信息密度
- [ ] 首屏内容是否控制在用户5秒内能理解主要功能
- [ ] 单页信息量是否过多（可考虑分步骤/折叠/分页）
- [ ] 是否有足够的留白避免压迫感

### 导航与流程
- [ ] 用户能否在3步以内到达核心功能
- [ ] 返回/退出路径是否清晰
- [ ] 当前位置是否有明确指示（面包屑/高亮菜单项）
- [ ] 表单是否有进度指示（多步骤场景）

### 常见布局错误
- [ ] 文字是否溢出容器或被截断
- [ ] 图片是否变形（aspect-ratio未保持）
- [ ] 弹窗/浮层是否遮挡关键操作区域
- [ ] 移动端横屏是否有异常布局

## 角色 2：内容审查官 — 详细检查项

### 违禁内容
- [ ] 无涉及政治敏感人物/事件的表述
- [ ] 无色情、裸露、性暗示内容
- [ ] 无宣扬暴力、血腥、恐怖的内容
- [ ] 无赌博相关功能或诱导语言
- [ ] 无针对特定群体的歧视或仇恨言论

### 知识产权
- [ ] 图片/图标/字体来源是否合法（开源协议/自制/授权购买）
- [ ] 品牌名称/LOGO是否有使用授权
- [ ] 文案是否原创或有合法引用来源

### 商业合规
- [ ] 宣传语中是否有无法证实的"最"/"第一"/"唯一"等绝对化用语
- [ ] 价格/折扣展示是否符合当地法规（价格法/广告法）
- [ ] 是否存在诱导好评、强制分享等违规引导
- [ ] 下载/安装是否捆绑其他软件

### 未成年人保护
- [ ] 如面向未成年人，是否有年龄验证机制
- [ ] 是否含有诱导未成年人消费的设计

### 隐私与合规
- [ ] 是否有隐私政策链接（收集用户数据时必须提供）
- [ ] 用户协议是否在注册/使用前可见
- [ ] Cookie/数据收集是否有明确告知和同意机制
- [ ] 是否符合 GDPR / 国内个人信息保护法（PIPL）要求

## 角色 3：代码审查官 — 详细检查项

### 语法与基础错误
- [ ] 变量/函数使用前是否已定义
- [ ] 括号、引号、分号等是否完整匹配
- [ ] 异步操作是否正确处理（async/await、Promise链）
- [ ] 类型转换是否安全（避免隐式转换导致NaN/undefined）

### 逻辑漏洞
- [ ] 循环是否有明确退出条件
- [ ] 递归是否有终止条件（防止栈溢出）
- [ ] 边界值处理：空数组、null、undefined、0、负数
- [ ] 文件/数据库连接是否在finally中关闭

### 安全漏洞
- [ ] SQL查询是否使用参数化查询（防注入）
- [ ] 用户输入是否在输出前转义（防XSS）
- [ ] 密码是否使用bcrypt/argon2等强哈希（禁止MD5/SHA1直接存储）
- [ ] API接口是否有权限验证（防越权访问）
- [ ] 敏感信息（密钥、Token）是否写死在代码中（应用环境变量）
- [ ] 文件上传是否验证类型和大小（防恶意文件）

### 性能问题
- [ ] 循环内是否有重复的DOM查询或数据库查询
- [ ] 大列表是否使用虚拟滚动/分页
- [ ] 图片是否压缩并使用懒加载
- [ ] 是否存在内存泄漏（事件监听器未移除、定时器未清除）
- [ ] 同步请求是否改为异步（避免阻塞主线程）

### 代码质量
- [ ] 函数是否单一职责，长度是否超过50行（建议拆分）
- [ ] 变量命名是否语义化（禁止a/b/temp等无意义命名）
- [ ] 复杂逻辑是否有注释
- [ ] 是否有重复代码块（建议提取为函数/组件）
- [ ] 硬编码的魔法数字是否提取为常量

## 角色 4：模拟用户 — 评价维度参考

### 用户角色选择指南
根据项目性质选择最具代表性的用户角色：

| 项目类型 | 推荐用户角色 |
|---------|-------------|
| 消费类APP/小程序 | 25~35岁普通用户，智能手机熟练使用者 |
| 企业管理工具 | 职场白领，有一定软件使用经验 |
| 儿童教育产品 | 儿童家长（30~45岁），代替孩子体验 |
| 老年人服务 | 60~70岁老年用户，初次接触智能手机 |
| 开发者工具 | 中级开发者，有2~3年编程经验 |
| 内容创作平台 | 业余内容创作者，兼职运营账号 |
| 医疗/健康类 | 普通患者或健康关注者，非医疗专业人士 |

### 评价维度权重参考
- 第一印象（20%）：3秒内的直觉感受
- 核心功能可用性（30%）：能否顺利完成主要目标
- 学习成本（20%）：不看教程能否自助使用
- 满意/不满意对比（20%）：情感化评价
- 推荐意愿（10%）：NPS（净推荐值）指标

### 星级评分参考标准
- ⭐️ (1星)：无法正常使用，存在严重问题
- ⭐️⭐️ (2星)：勉强可用，但问题多，体验差
- ⭐️⭐️⭐️ (3星)：基本达标，有明显改进空间
- ⭐️⭐️⭐️⭐️ (4星)：整体良好，小瑕疵不影响使用
- ⭐️⭐️⭐️⭐️⭐️ (5星)：超出预期，体验极佳
