# 多维度项目审查专家 - README

> 一个为 Claude/OpenClaw AI 设计的专业项目审查 Skill，提供从 UI/UX、内容合规、代码质量到用户体验的 4 维度全方位审查。

---

## 📋 概述

**多维度项目审查专家** 是一个系统化的项目审查工具，能够依次扮演 4 个独立角色对用户提交的项目进行全面评估：

| 角色 | 职责 | 审查重点 |
|------|------|----------|
| 🎨 创意审查官 | UI/UX 设计师 | 排版布局、视觉层级、交互流程 |
| 📜 内容审查官 | 平台审核员 | 合规性、安全性、隐私政策 |
| 💻 代码审查官 | 资深工程师 | 语法错误、安全漏洞、性能问题 |
| 👤 模拟用户 | 真实用户体验 | 第一印象、痛点、评分推荐 |

---

## 🚀 快速开始

### 安装方式

#### OpenClaw AI 用户
```bash
# 将 SKILL.md 放入 skills 目录
~/.openclaw/skills/multi-review/SKILL.md
```

#### Claude 用户
直接将 `SKILL.md` 内容作为系统提示词或项目上下文注入。

### 触发词

只需在对话中包含以下任意关键词：

- **中文**：`审查项目`、`代码审查`、`全面审查`、`帮我 review`、`四角色审查`
- **英文**：`review`、`project review`、`code review`

### 使用示例

```
用户：帮我审查这个登录页面的代码和界面
[附上 HTML/CSS/JS 代码或界面描述]

AI：
【创意审查结论】部分通过
【发现的问题】按钮与输入框间距不一致...
【改进建议】统一使用 16px 间距...

=== 下一角色 ===
【内容审查结论】需整改
【违规风险点】"记住密码"选项未说明数据存储方式...
...
```

## 🎯 核心特性

### 1. 完整的审查维度
- ✅ 视觉层级检查（对比度、字号、间距）
- ✅ 合规性扫描（广告法、隐私政策、未成年人保护）
- ✅ 代码安全审计（SQL注入、XSS、越权风险）
- ✅ 用户角色模拟（按年龄+性别+MBTI随机生成）

### 2. 结构化输出
每个角色输出固定格式，便于自动化解析和问题追踪：
```
【角色结论】通过/部分通过/不通过
【发现的问题】逐条列出
【改进建议】可执行的具体方案
```

### 3. 智能用户模拟
自动根据项目类型选择最合适的用户角色：
- 消费类APP → 25~35岁普通用户
- 开发者工具 → 中级开发者
- 儿童产品 → 家长视角
- 老年人服务 → 60~70岁银发群体

支持随机 MBTI 人格（16型全支持）

## 📊 输出示例

```
【创意审查结论】部分通过
【发现的问题】
1. 按钮与输入框间距不一致（间距分别为 8px 和 16px）
2. 错误提示文字颜色对比度不足（#FFAAAA 在白色背景上）
【改进建议】
1. 统一使用 8px 倍数间距：8/16/24/32px
2. 错误提示使用 #D32F2F（对比度 4.8:1）

=== 下一角色 ===
【内容审查结论】合规
【违规风险点】无
【修改建议】无

=== 下一角色 ===
【代码审查结论】有风险
【具体错误/风险】
- 第 23 行：密码使用 MD5 存储（已知不安全）
- 第 45 行：SQL 语句拼接用户输入（存在注入风险）
【修复建议】
1. 使用 bcrypt（cost=10）替代 MD5
2. 改用参数化查询或 ORM

=== 下一角色 ===
【用户角色设定】
- 年龄段：30岁
- 性别：女
- MBTI：INTJ
【综合评分】⭐⭐⭐☆☆
【是否会推荐】视情况而定（修复安全问题后才会推荐）

=== 综合总结 ===
【最关键改进项】
1. 【严重】修复 SQL 注入漏洞（角色3）
2. 【高优先级】统一间距规范（角色1）
3. 【中优先级】更换密码哈希算法（角色3）
```
